Kubernetes Operations

Kubernetes is a reconciliation engine. Everything you operate is a desired state someone declared.

Kubernetes is not a container orchestrator so much as a control loop that continuously drags reality towards a declared spec. Once you hold that model, the commands and the failures both become predictable. This course follows a workload from a manifest to a running pod and then breaks it in the ways it actually breaks in production.
